骨架（照评论原文）：状态细条 → 单栏内容流 → 屏底动作区。门是**原地渲染的浮层**不是路由（没有导航层级可言）；账号屏的列表只有**台账行**（宋体序号住 18px 槽 + 两行事实，无表头无外框）；每屏唯一的持久动作住屏底 dock。展示字 = 宋体（Songti SC 族），正文 = 苹方（PingFang SC 族），不同族。

## 逐屏：触发 → 反馈 → 失败落点

逐屏交互对 `接口契约-签名与错误码全集`。评论屏清单（iPhone 390×844 ×6 + iPad ×1）与 `design/m5/` 下 7 个 html 一一对应，无多无少。

### 01 门 · 常态（双通道）· `01-gate.html`（U5.1+U5.2，主态）

| | |
|---|---|
| 触发 | 未登录进入。空态 = 不存在：门不发首屏请求，这是规格给的定论，不是留空 |
| 反馈 | 微信 + Apple 双通道（App Store 审核要求）：同形态（1.5px 描边块）、同尺寸（52px 满宽）、同层级上下排；不用实心黑是为保住底座「主按钮 = 满宽实心块全屏唯一」的认形规则。发码：①人机验证（失败就地重来、不消耗发送次数）→②③单号/单 IP 频控（超限给准确时点）→④下发；`/auth/sms/send` 成功带重发间隔与验证码位数（格子按响应位数渲染，稿按 6 位画） |
| 失败落点 | `/auth/sms/send` 区分频控 / 需人机 / 通道故障 / 未开通四档；超时不自动重发。微信 / Apple：取消授权静默回门不报错；拿不到跨应用身份 → 受限态引导换手机号、不降级建号；通道未开通 / 本端不支持 → 整行不渲染，不做灰按钮 |

⚪ 前提留产品经理裁决：若最终不上架 App Store，砍掉 Apple 通道一行即可，其余不动。`U5.3` 缺口表 `L-1`「现在不画」按 09-04 iOS 首发口径覆盖执行。

### 02 门 · 已发码 + 页内错误 · `02-gate-sent.html`（U5.2，失败态·页内档）

| | |
|---|---|
| 触发 | 发码成功落本屏；填满自动提交、主按钮同留 |
| 反馈 | 重发倒计时按响应值；码格清空保焦、手机号不清；四句终态之一「输错·还能再试 3 次」。协议版本走 `GET /auth/agreements/current` |
| 失败落点 | `/auth/sms/verify` 区分码错（带剩余次数）/ 过期 / 已用过 / 已作废 / 锁定（带解锁时点）五档 → 四句不同的话；连错达上限落屏 03。未勾协议不发请求（页内提示 + 协议行动一下）；协议正文拉不到不当已同意 |

### 03 门 · 受限态（锁定）· `03-gate-locked.html`（U5.1/U5.2，受限态）

| | |
|---|---|
| 触发 | 校验连错达上限（锁定档，响应带解锁时点） |
| 反馈 | 给准确时点 22:10、不写成故障；换通道两条路仍在，受限态里两条通道同为出路 |
| 失败落点 | 关闭永不禁用 —— 没有任何一个态把用户堵死 |

### 04 账号屏 · 只绑微信 · `04-account.html`（U5.3 + U5.5/U5.6 入口，主态 WECHAT_ONLY）

| | |
|---|---|
| 触发 | 登录成功进入 |
| 反馈 | 弱提示条一行可点不弹窗；无昵称头像。设备区 `GET /tokens` 独立区块。「导出」住进账号屏 dock 当唯一持久动作 ——「在任何登录态下都在、永不禁用」在版面上兑现。退出 × 注销两档区隔：退出 = 台账行常规条目、注销 = 屏底小字文本链接，形态 / 位置 / 字级三重区隔，两条 sub 各自写明碰不碰原图（「原图一张不动」 vs 「原图也会一起删掉，不可恢复」） |
| 失败落点 | 设备区拉不到单独错误 + 重试，不挡导出与退出；「退出这台」= `DELETE /tokens/{id}` 立即生效 |

### 05 退出 · 确认浮层 · `05-logout.html`（U5.6）

| | |
|---|---|
| 触发 | 账号屏「退出」；先查本地队列（不发请求），有未传先拦一次 |
| 反馈 | 说清「什么不会没」：原图一张不动 / 已同步重新登录就回来。主按钮 = 再想想（焦点默认在退路）；退出为次按钮、非危险色（可逆）。确认后只吊销当前令牌、清令牌会话与已同步缓存、不碰原图 |
| 失败落点 | 拦截形态 `L-5` 未定：稿只画队列为空的确认层，拦截支留位置不画按钮 —— 照实登记，不补设计。离线允许本地退出、拦截照做 |

### 06 注销 · 明确告知浮层 · `06-deactivate.html`（U5.5）

| | |
|---|---|
| 触发 | 账号屏屏底小字文本链接进入 |
| 反馈 | 第 2 步只说一次：主 = 先导出一份，次 = 直接注销；按「立即删除」写、无找回入口（`L-3` 待律师稿）；红色只留给第 4 步打字确认。`DELETE /account` 幂等；响应带导出入口提示（第二次给导出，兜底）；吊销全部令牌立即生效；成功后删本机原图与缓存、回门说明一次 |
| 失败落点 | 第 4 步打字确认（输入「注销」，C-DANGER 三档、全产品唯一打字处）**未单独出稿**，按 U5.5 §七执行 —— 评论有此交互、html 无此屏，差异照实登记 |

### 07 iPad 门 · 常态 · `07-ipad-gate.html`（U5.1，720–1023 放宽档）

| | |
|---|---|
| 触发 | 720–1023 竖屏进入登录门 |
| 反馈 | 只放宽、不改信息顺序 —— 左边线 24→32px，内容最大宽 640px 居中，不引侧栏。不把退出 / 注销两个入口排同一行（通道按钮同理，排一行会看成一主一次） |
