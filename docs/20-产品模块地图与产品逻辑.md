## 一、一句话产品逻辑:这是一个减法

**盲区 = 骨架层 − 行为层。**(定义在 `13` §1.4,本文不改)

整个产品只有两件事:**把被减数维护好**(考点全集),**把减数收全**(用户实际碰过的)。
剩下的每一个模块,要么在减法的左端,要么在右端,要么是把差值送出去的出口。

**判断任何一个模块该不该存在,先问它在这个减法的哪一端。** 答不上来的,进 §七 待裁定,不硬塞进某个模块。

**唯一的产出是覆盖度,所以宁可丢弃率高,不可准确率低**(`01` §2.2 / `13` §1.3)—— 归错会让覆盖度失真,
而覆盖度失真的话,这个产品就没有指标了。

## 四、产品主逻辑流

三条线,一条主干两条分支。**主干上任何一步失败,记录都必须已经落地了。**

```mermaid
flowchart TD
    subgraph LEFT["A 骨架层 · 被减数"]
        SY["考点全集<br/>三层树 + 频次四统计"]
        ARC["归档节点<br/>同时退出分子与分母"]
    end

    subgraph RIGHT["B → C · 减数"]
        CAP["四个入口<br/>语音 / 拍照 / 粘一段 / 记做题"]
        W["立刻落地<br/><b>不依赖任何模型</b>"]
        TAG["打标管线<br/>召回 → 闭集 → 阈值 → 自检"]
        UNC["未分类<br/><b>不进行为层</b>,等用户自己挑"]
        BEH["行为层<br/>已挂考点的记录"]
    end

    CAP --> W --> TAG
    TAG -->|"命中且过阈值"| BEH
    TAG -->|"NO_MATCH 或低于阈值"| UNC
    TAG -->|"服务不可用"| RETRY["待补队列<br/>记录已经在了"]
    UNC -.->|"手动挂载"| BEH
    RETRY -.->|"恢复后重试"| TAG

    SY --> DIFF{"<b>差集</b>"}
    ARC -.退出.-> SY
    BEH --> DIFF

    DIFF --> BLIND["<b>盲区清单</b><br/>北极星的落点"]
    BLIND --> E1["空白清单 / 先补这几个"]
    BLIND --> E2["问 AI 时带上的东西<br/>⚠ 契约缺口 · §七-①"]

    BLIND --> E4["MCP / CLI 只读"]

    style LEFT fill:#eef,stroke:#557
    style RIGHT fill:#efe,stroke:#5a5
    style BLIND fill:#ffe,stroke:#a95
    style E2 fill:#fee,stroke:#a55
```

**这张图里有两条线不能动:**

1. **`W` 在 `TAG` 之前** —— 识别、转写、打标全部在落地之后。任何把识别放到写入之前的重构,都是在拆掉

2. **`UNC` 不进 `BEH`** —— 记了但没认出来 ≠ 碰过这个考点。计进去就是拿记录数冒充覆盖(`13` §1.4)。

## 六、边界层:脑图的负空间

**这一节和 §二 那张图同等重要。** 产品的形状一半由它做什么决定,一半由它**结构上做不到什么**决定。

| 边界 | 落到产品上是什么形态 | 真源 |
|---|---|---|
| **永不判断「对不对」** | 界面与输出中不出现正确率、得分、排名、讲解、学习建议、复习提醒、连续打卡、成就徽章 | `01` §2.2、🔴`R-05` |
| **不做学科教研** | 学科判断一律外包给外接模型;产品只做上下文组装与原样透出,不摘要不评分不加工 | `11` §5.2 |
| **不存题干与机构内容** | **库里不存在能装下题干的字段,连预留位都不留**;只记来源名称与时间 | 🔴`R-01` `R-06`、`10` §5.1 |
| **不生成标签文本** | 自动打标只能从候选集里选一个 id 或返回不匹配 | 🔴`R-07`、`10` §6.3 |
| **匹配不上就丢弃** | 未分类可见但不计覆盖度。**宁可丢弃率高,不可准确率低** | `13` §1.3 |
| **原图不上云不共享** | 到期转本机归档;不做任何形式的图片分享或外链 | 🔴`R-04`、`10` §8.1 |
| **盲区诊断与导出永不上锁** | 两条不可逆决策,不是产品偏好 | 🔴 `11` §二 |
| **不做积分 / 成长体系 / 签到打卡** | 它奖励的是打开次数,而北极星是主动查看盲区的人数 —— **用一个更容易涨的指标代理一个更难涨的指标,是把指标本身换掉** | `10` §十 |
| **提案数与投票数不进任何看板** | 同上一条同构 | `16` §五 |

**最后三条是同一条。** 注册数、日活、使用时长、打开次数、提案数 —— 每一个都能靠别的手段做高,
而且做高了**不会让任何一个人多看一次自己的盲区**。

## 七、三个缺口:前端有行为、后端无契约

**以下三项我不裁定。** 每一项都是**同一种形状**:界面侧已经有了明确意图(甚至已经画进稿子),
而后端契约里没有对应的位置。按我的边界,产品可以指出缺口,**契约由技术同事定**。

### ① 「问 AI 时带上的东西」两条路径都没有接口契约 🔴 最要紧的一条

| 事实 | 出处 |
|---|---|
| 免费复制路径 `D8`/`H8` **已经存在**,但 `01`–`10` 未收录 | `11` §5.3 原话 |
| 付费代发的**行为**写在 `11` §五 | `11` §5.1 |
| `10` §6.7.1 提到「**代发端点**」的内部扣减时机 | `10` §6.7.1 |
| `10` §六 的契约表里**没有任何一行**是这两条路径 | 通读 §6.1–§6.7 |

**为什么这一条排第一:它接在北极星指标的正下游。** 关卡 2 的第二个判据是「看到缺口清单后点进去的比例」
(`04` §2.2「第二个指标最关键」),而用户点进去之后,产品给他的**下一个动作**就是这个 ——
把上下文复制出去问模型。这条路径没有契约,意味着**北极星落点之后的第一步是靠记忆传递的**。

**需要谁做什么:** 技术同事补 `10` §六 的契约行(免费组装 + 付费代发各一行),
并明确「组装上下文是零边际成本、不计费」(`11` §三 已给规则)在端点层怎么体现。

### ② 「我卡住了」反向断言:契约缺席

`10` §6.4 的断言端点**只有正向**(「我已掌握」),`13` §1.1 的全景图里也没有它。
`08` `1.4.5` 已经把它登记为待办,并写了它的诊断价值高于正向 ——
**因为「碰过但没通过」这一类,在 `盲区 = 骨架层 − 行为层` 里现在完全不可见:碰过就算覆盖。**

**这不是要现在做。** `08` `1.4.5` 挂在「阶段 3+,只列节点不排期」,现在动它就是 `R-85` 的又一个实例。
登记在这里的原因只有一个:**它是差集定义本身的一个已知盲点**,不是一个功能待办。

### ③ 退款:界面已画,后端从未定义 ⚪

`13` §1.11 自己登记了这个缺口:`notetool-ui-a` D18 的订单列表里已经有一笔已退款订单,
而「退款之后额度和权益怎么算」全文档集无处定义。`13` 给了 A/B/C 三种写法与各自后果,
并指出**规则属于用户协议,架构定不了,待 `L-A5` 律师稿**。

**产品侧要补的那一半,律师稿替不了:** `13` 的写法 C(按已用比例扣退款金额)**必须在支付页事先讲清楚,
否则是事后改规则**。「支付页上写什么」是产品的事,不是律师稿的事,也不是架构的事。
本文只登记这半格是空的,**不裁定选 A / B / C**。

## 八、这份文档最容易被用错的方式

| 用错的方式 | 为什么是错的 |
|---|---|
| **拿它当产品设计** | 它只有模块名与归属。每个模块具体长什么样,在设计稿与 `10` / `13` 的契约里。**这里写得越细,就越会变成第二处说法** |
| **拿 §三 那四格去砍端或砍模块** | 与 `00` §七 同一条:那一格是让事实可数,不是删除许可。砍不砍是人的裁定 |
| **把 §七 的三个缺口当 TODO 自己补上** | 缺口的形状是「前端有行为、后端无契约」。产品自己去补契约,补出来的就是第二份契约。**指出缺口是产品的活,定契约不是** |
| **把它当进度** | 画完模块图不等于任何一格推进了。自检仍只看 `08` §六那一条:`1.1.4` 那张表有没有在填 |
| **在这里写新的产品判断** | 本文只有结构与指针。任何新判断都属于它归属的那份文档 |

**最后一条,和 `04` 与 `10` 的结尾同一句:产品不是变量,需求才是。**

## 九、为什么只有 A–E 有展开文档,F / G / H / X 没有
