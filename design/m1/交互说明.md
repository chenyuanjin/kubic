## 逐屏：触发 → 反馈 → 失败落点

### 01-write · 写 · `01-write.html`（U1.4 / U1.1 共用骨架）

| | |
|---|---|
| 触发 | 空态：默认入口进来那一刻，输入已聚焦，占位符真源原文 |
| 反馈 | 「记下」禁用 35% 且旁边说得出缺什么（内容约束，不是等响应） |
| 失败落点 | 空输入禁用（禁用理由就地说明）；超长本端截断照常提交；剪贴板永不主动读 |

### 02-photo · 拍 · `02-photo.html`（U1.3 + 留存三处）

| | |
|---|---|
| 触发 | 原图拍下即落本机、早于记录 |
| 反馈 | 主态：rec.html 定稿样板照用，仅补段控；`POST /records/{id}/image` 同四档 |
| 失败落点 | 识别失败原图仍在本机；张数上限本屏拦、已拍照样记；请求体无任何指向已上传文件的引用 |

**留存三处在本屏可指认**：① 勾选「留下这张原图」+ 承诺句 ② 「还有 2 天 6 小时转进留存区」+ 附加句 ③ 「立即删除原图」常驻同号字。三处同区块、同左边线、同号字，文案字节级取自底座 rec.html（半角逗号）。

### 03-voice · 说 · `03-voice.html`（U1.2）

| | |
|---|---|
| 触发 | 松手那一刻落本地；下方录音中（按住 85% + 波形 + 时长，不逐秒播报） |
| 反馈 | `POST /records/{id}/audio` 四档可判别——成功回填 |
| 失败落点 | 无有效语音 ‹重录› / 5xx·超时 ‹重试›（C-ERR 停卡片）/ 额度不足走受限态；转写失败停 TS-00 不推进标签轨；权限被拒就地切打字（输入框已聚焦，去设置是文本按钮）。失败态：转写没成——记录在、内容为空是正常初值，三条并列出口（重录 / 补一句文字 / 自己挑考点） |

### 04-quiz · 做题 · `04-quiz.html`（U1.5）

| | |
|---|---|
| 触发 | 主态：树选择器只选不建，无标签轨徽标 |
| 反馈 | 未选时「记下」禁用同 01 口径 |
| 失败落点 | `GET /syllabus/tree` 失败只空本模式、可切走；带节点标识的记录不进打标管线，已同步直落 TS-03；考点被归档→提示重选（与服务出错两档分开） |

### 05-quota · 受限态 · `05-quota.html`（U1.1 §6.3）

| | |
|---|---|
| 触发 | 额度耗尽 |
| 反馈 | Toast「已记下」、台账行「稍后再认 · 这次没自动归类，先进未分类」、‹自己挑考点›‹看看档位›（文本按钮） |
| 失败落点 | 无红色、无重试当主操作、主按钮照常可点——额度耗尽时记录仍成功，这一态不是失败 |

### 06-timeline · 时间线与删除 · `06-timeline.html`（U1.7 + U1.6）

| | |
|---|---|
| 触发 | 主态 + 删除确认 |
| 反馈 | 顶条「正在同步 2 条」（只有条数）、按天分组、分组头不放条数、徽标照抄十态表；队列：联网自动补传，无手动同步按钮 |
| 失败落点 | 5xx/超时留队自动重试用户无感，4xx 停在时间线那条卡片给 ⟨删掉它⟩/‹改一下再传›（入口位置是 M1-G16 待人拍板，稿内未落）；带图逐条走图片通道，用户侧表现与纯文本一致。删除：浮层确认（先说盲区数字会变、原图不受影响）→ `DELETE /records/{id}` 级联删标签、触发重算；当日计数不减；离线可删。重算中间态（G-4）与可逆性（G-5）真源未定，稿内未替拍板 |

### 07-ipad · iPad 档 · `07-ipad.html`（核心屏 iPad 横屏）

| | |
|---|---|
| 触发 | ≥1024 横屏（1366×1024） |
| 反馈 | 双列内容：左栏是内容不是菜单——时间线回看整栏，随筛选整栏换掉；右栏 464px 采集列，画的就是录音窄态（分屏/台前调度下的宽度：波形与计时纵排、按钮满列宽、组件不换形）。「记一条」入口仍住屏底动作区，不挪进左栏 |
| 失败落点 | 信息顺序与 iPhone 档完全一致，只改排布；额度耗尽仍成功那一态两档都画了：iPhone 在 05，iPad 在 07 左栏首行，同一副样子（稍后再认 + 同一对文本出口），与 KUBI-87 共用判据 |

## 它服务于哪个关卡

**从「记第一笔」到「一周内还会记第二笔」。** 记录是整个产品的输入端——这里断了，盲区就是空的，唯一那个数直接归零。

## 成功的可观测信号

**记录动作成功率 100%**（含离线、含额度耗尽两种情况）；二次记录率。
