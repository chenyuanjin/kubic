## 逐屏：触发 → 反馈 → 失败落点

⚪ 差异登记：交付评论的逐屏交互按**交互**分组成 6 条（01 与 05 合写一条、08 无单独条目，靠「iPad 左栏判据」段与屏清单行覆盖），不是逐文件 8 条。下面按 html 逐文件拆开登记，引文原样，未给的行照实标注，不补。

### 01 盲区总览 · 主态 · `01-blind.html`

U3.2，底座定稿样板照用：竖式 120−43=蓝面 77，注脚四行，口径行，台账行两行一格。

| | |
|---|---|
| 触发 | 点「碰过/没碰过/注脚」 |
| 反馈 | 就地筛选榜（05 即注脚点开后的态） |
| 失败落点 | 列表拉取失败只榜位出局部错误块 + 局部重试，摘要不动、不整屏报错（对 `GET /coverage/summary` 与 `/coverage/blindspots` 并发各自独立） |

### 02 盲区总览 · 空态（有骨架零记录）· `02-blind-empty.html`

U3.2 `EMPTY_NO_RECORD`：恒等式为 0 也显示，蓝面 = 整张表 120，第一句话「你还没记过东西」，两个入口。盲区是满的，不是出错。

| | |
|---|---|
| 触发 | 记一条；先看看有哪些考点 |
| 反馈 | 记一条 → 记录流；先看看有哪些考点 → 骨架树 |
| 失败落点 | 骨架缺失是另一张空态（一个数都不显示），本稿画的是零记录档 |

### 03 盲区总览 · 重算态 · `03-blind-recalc.html`

U3.2 `RECALCULATING`：数字位全占位块，屏幕上找不到旧值；归档/未分类照常；排序筛选禁用并就地给理由；榜骨架统计照常、行仍可点；「我已经会了」禁用。

| | |
|---|---|
| 触发 | 服务端标记重算 |
| 反馈 | 数字位换占位块（不删除线、不调透明度、无旧值） |
| 失败落点 | 重算超时转错误态不回退旧数字；行仍可点进详情看骨架事实 |

### 04 按章看全部 · 骨架树 · `04-tree.html`

U3.5：三层、非叶子右侧只有两个计数、三态靠文字（●/○ 只是辅助）、树内搜索占位符不给示例、树底归档区常驻（0 也在）。

| | |
|---|---|
| 触发 | 进树（`GET /syllabus/tree` 一次返回不懒加载）；折叠；树内搜索 |
| 反馈 | 折叠只折自己不做手风琴；搜索只搜名称、词不进 URL、无结果不给「新建」 |
| 失败落点 | 拉树失败整屏错误态 + 重试，归档区一并缺席 |

### 05 断言注脚点开 · 筛「我标了已经会了」· `05-assert-filter.html`

U3.6 效果落点：摘要三个数一个不变，注脚是「概览不减断言 / 榜排除已断言」两条契约之差的就地解释，榜位换成断言集合 4 行。

| | |
|---|---|
| 触发 | 点注脚（05 即注脚点开后的态） |
| 反馈 | 就地筛选榜；摘要三个数一个不变，榜位换成断言集合 4 行 |
| 失败落点 | 与 01 同一条：列表拉取失败只榜位出局部错误块 + 局部重试，摘要不动、不整屏报错 |

### 06 我要考的那一场 · 档案屏 · `06-exam-profile.html`

U3.8：文案逐字照 `问一下` §2.5（你要考的是哪一场？/ 考试 / 考试日期 / 好了 / 以后再说）；闭集全集、日期不预填、屏上没有任何天数、没有进度点。

| | |
|---|---|
| 触发 | 「好了」；「以后再说」 |
| 反馈 | 好了（两格都空点它等同跳过，不调 PUT）/ 以后再说（不写任何东西、不记「他跳过了」、不再自动出现）→ 都落到 S-ASK 开屏 |
| 失败落点 | 写入失败停在原地一行说明 + 可重试，也可直接往下走（`PUT /profile/exam` 全量覆盖，存档路上不存在「你填错了」） |

### 07 iPad 横屏 ≥1024 · 双列（行政法）· `07-ipad-blind-a.html`

U3.2+U3.4：左栏 = 这一科的竖式摘要 + 蓝面 + 骨架树；右栏 = 选中考点详情（区 5 断言开关只在这里发起）。右栏为空时「从左边挑一个考点」，不自动选中第一个。

| | |
|---|---|
| 触发 | 点 ⊙—（断言开关，只在右栏详情发起） |
| 反馈 | 乐观更新、榜里该行消失、注脚 +1、三个数不变（`POST /assertions` 只收节点标识） |
| 失败落点 | 失败回滚 + Toast「没标上，再试一次」；归档节点禁用并就地给理由。重算中开关不禁用 |
