# 产品模块脑图

## 零 · 本文是什么 · 怎么打开

- **整份文件就是一张脑图的源。** 用 markmap 打开是可折叠、可缩放的脑图；不装任何东西打开，
  它是一份可读的缩进大纲 —— 两种读法内容完全相同。**图坏了内容不跟着坏**，这是选它的第一条理由
- **本文只回答「有什么、挂在谁下面」**
  - 凡是有方向的东西 —— 流程、状态、转移条件、失败分支 —— **一律不进本文**，
    在 [`模块 A · 骨架层`](modules/模块A-骨架层.md)–[`模块 G · 商业化`](modules/模块G-商业化.md) 各模块文档里，图一律用 Mermaid
  - 两种图各管一件事，这条边界是为了本文不再长成一张什么都塞的大图
- **一个字段、一个数字、一条判据都不定义**
  - 模块名全部取自既有文档，不发明
  - 节点后的 `｜` 后缀只写约束与指针，**不写「什么时候做」** —— 排期在 [`总路线图 · 脑图与父子待办`](../execution/INDEX.md)，本图不复述
- **基线**：`origin/v1` @ `afab5a7`，fetch 于 2026-08-31T05:20Z（`模块 F · 账号与端` `模块 G · 商业化` 补齐那一轮）
- **状态：活跃** ｜模块增删、或某模块在减法里的归属被人裁定，本文与 `产品模块地图与产品逻辑` §三 在同一次改动内更新
- **本文不产生任何一个关卡数字** ｜关卡要的是 `1.1.4` 那两个每日数字（`实施路径` §阶段0），画脑图一个数都不产生
- **怎么打开成脑图**
  - `npx markmap-cli docs/product/产品模块脑图`，或 VS Code 装 `markmap` 扩展后在本文右上角点预览
  - 不打开也不影响读 —— 下面就是全文
- **回索引**：[文档索引](../INDEX.md) ｜ 模块总表在 [`产品模块地图与产品逻辑`](INDEX.md) §三
- ⚠️ **本文不用块引用（`>`）**
  - markmap 把块引用渲染成挂在标题下的游离节点，脑图会被头注污染
  - 该写的话一律写成列表项，让它成为树上一个有位置的节点

## B 采集层 · 减数的入口

- 四个入口 → [`后端系统设计与组件接入`](../technical/后端系统设计与组件接入.md) §1.2
  - 语音记 ｜≤60s
  - 拍照记 ｜单次 ≤6 张
  - 粘一段
  - 记做题 ｜用户已自选考点，不走打标
- 一次写入 · Touch
  - 时间戳 + 来源名称 + 形式
  - 🔴 没有能装转写文本或题干的字段
  - 🔴 请求体没有 audioUrl / imageUrl / fileId
- 记录动作永不失败 ｜全程
  - 立刻落地在识别之前
  - 任何把识别放到写入之前的重构都在拆这条线
- 离线队列 ｜采集端的，不是服务端的
  - 本地排队，队列条数可见
  - 补传按 client_token 去重 · 单批 ≤50
- 原图 · 本机留存与到期归档 → [`原图存储：判据层与存储层`](../technical/原图存储-判据层与存储层.md)
  - 🔴 base64 内联一次即弃
  - 🔴 不上云 不同步 不共享 无分享入口
  - 到期转归档，不是删除

## C 打标层 · 减数的成形

- 四段管线 ｜三段的作用是丢掉 → `后端系统设计与组件接入` §1.3
  - ① 候选召回 · 缩到 5–10 个
    - 召回为空 → 不调模型 → 直接未分类
  - ② 闭集分类 · 只从候选里选 id
  - ③ 阈值裁决 · 低于阈值 → NO_MATCH
  - ④ 出口自检 · code 不在候选集 → 降级 NO_MATCH
- 🔴 永不生成标签文本
  - 接口只收 nodeId，不收 name → `R-07`
- 两种失败必须是两句不同的话
  - 模型说不匹配 → 自己从树里挑
  - 模型没看成 → 稍后重试
- 未分类 ｜可见但不计覆盖
- 手动挂载 ｜从树里选，不能新建
- 待补队列 ｜服务恢复后自动重试

## D 差集层 · 减法本身

- 盲区 = 骨架层 − 行为层 → `后端系统设计与组件接入` §1.4
- 覆盖度 = 行为层 ÷ 骨架层
  - 分母 = 未归档的 level 3 节点
  - 分子 = 有 ≥1 条已确认标签的节点
- 三条计算规则
  - 未分类不计入行为层
  - 已归档同时退分子与分母
  - 归档计数常驻可见 ｜`R-49`
- 断言
  - 我已掌握 · 正向
  - 我卡住了 · 反向 ｜未定义 · 缺口 → `模块 D · 差集层` §六
- ⛔ 不产生任何「对不对」的判断
