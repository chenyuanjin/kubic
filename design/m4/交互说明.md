骨架一句话（评论原文）：单屏 `S-EXP` 一条内容流：状态细条 → 台账头（返回 + 屏题）→ 范围选择行（固定，改一次四区一起重算）→ 四个区自上而下滚动（导出 → 免费复制 → 付费代发 → 只读令牌，顺序是产品判断：付费永远压在免费之下）。展示字宋体（Songti SC 系），正文苹方（PingFang SC），不同族。

## 逐屏：触发 → 反馈 → 失败落点

四态口径（评论原文，各屏共用）：主态（exp / exp-ask）、空态（exp-empty）、失败态（exp-err，六档错误里画上游中断档，其余五档共用此落点、每档一句不共用文案）、受限态（exp-limit 画缺额度档；缺登录档同构 —— 去登录同为次按钮，区一区二照常）。每屏交互都收敛到同一条：**失败停在发生的那一区，免费两区没有失败态也没有禁用态（禁用成因只有加载中与无数据）**，落点对得上契约的四档区分（缺骨架/缺额度/缺登录/请求失败）。

### `exp` 主态首屏 · `exp.html`（U4.1/U4.2/U4.4）

| | |
|---|---|
| 触发 | 评论未单列；屏定位原文「主态首屏」，即进入出口屏的默认态 |
| 反馈 | 区一（格式三选 + 导出 + 边界小字原文）+ 区二（边界小字 + 模板预览）；范围选择行固定，改一次四区一起重算；全屏唯一主按钮是区一「导出」——它就是那条永不上锁的免费兜底 |
| 失败落点 | 收敛条款：失败停在发生的那一区，免费两区没有失败态也没有禁用态 |

### `exp-ask` 主态下半屏 · `exp-ask.html`（U4.5/U4.6/U4.7）

| | |
|---|---|
| 触发 | 评论未单列；屏定位原文「主态下半屏」（区三区四滚动可达） |
| 反馈 | 区三回答完成态（模型名/备案标识/引文区/复制回答/接着问）+ 区四令牌列表（最后使用时间常驻、吊销一步）。回答区是左缘压墨线的引文（上标模型名与备案标识、下标「这是你接的模型给的回答」），产品自己的话与模型的话在版面上分开 —— 一眼可见这是把盲区打包交给你自己接的外部模型，不是内置老师在答题 |
| 失败落点 | 区三流中断落 `exp-err`（上游中断档）；收敛条款同上 |

### `exp-empty` 空态 · `exp-empty.html`

| | |

### `exp-err` 失败态 · `exp-err.html`

| | |
|---|---|
| 触发 | 流中断（六档错误里画上游中断档，其余五档共用此落点、每档一句不共用文案） |
| 反馈 | 已收到部分原样保留 +「只收到一半」+「这次没算次数」明写；重试是次按钮，区一区二一格没动 |
| 失败落点 | 本屏即失败落点本体：失败停在发生的那一区（区三），免费两区不受牵连 |

### `exp-limit` 受限态 · `exp-limit.html`

| | |
|---|---|
| 触发 | 额度 0（缺额度档；缺登录档同构 —— 去登录同为次按钮，区一区二照常） |
| 反馈 | 区二原样可用在上，区三「回到上面那段文字复制」为次按钮、付费入口只是文本按钮「次数怎么加」；不弹窗不遮罩不折叠免费区 |
| 失败落点 | 受限只锁区三，免费两区没有失败态也没有禁用态 |
