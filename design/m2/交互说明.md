# M2 交互说明（打标与未分类）

内容搬运自子议题 KUBI-83 的交付评论（comment `01a06d2b-391f-78f9-8d21-825eaac79712`，2026-09-04）与该子议题 description，措辞保持原样，不改写口径。
工程 `kubi-83-m2-v10`，抄写源 `kubi-80-v10-blueprint`；子议题基线 `origin/v1` @ `81a2c23`。
骨架（交付评论原话）：每屏都是「状态细条 → 单栏内容流 → 屏底动作区」。展示字宋体（Songti SC，状态位与树的层级行），正文苹方（PingFang SC）。蓝面 0 块 —— 蓝面恒定含义是「你还没碰过的那部分」，M2 里没有这句语义，不硬用。
屏清单以 `design/m2/` 下六个 html 为准（5 iPhone + 1 iPad），与交付评论的屏清单逐一对得上，无多无少。

**登记一处差异**：交付评论的「触发 → 反馈 → 失败落点」一部分随屏清单逐屏写了，另一部分收在文末一段聚合登记里（候选确认乐观更新 / 挂载只传节点 id / 四成因错误码对照）。下表按屏拆开搬运，每格都是评论原句；评论没写到的格标「交付评论未登记」，不替它补设计。

## 逐屏：触发 → 反馈 → 失败落点

### `m2-tag-main` · S-TAG 整屏（U2.4 §6.1，TS-02，主态）

| | |
|---|---|
| 触发 | S-TAG 无常驻入口、不在任何 Tab 里，永远是从别处推进来的一层 |
| 反馈 | 顶部只有返回与「7 条还没对上」计数（不做进度条）；A 记录卡 / B 候选 / C 都不是 / D 自己挑一个 / E 已挂 / F 看看丢掉的 / 底栏跳过；屏底动作区只放「跳过这条」这一个退出动作；状态位下一句：「候选只从你的考点表里来，对不上就不挂」；候选确认乐观更新 |
| 失败落点 | 失败回滚且覆盖度一起退回（U2.2 §7.2） |

### `m2-tree` · 树选择器覆盖层（U2.4 §6.2，主态）

| | |
|---|---|
| 触发 | 候选集选择两档同用整屏 sheet，不做 popover |
| 反馈 | 搜索 + 三层树 + 已挂置灰「已经挂过了」+ 归档分组可见不可挑 + 挂上去；全稿无「新建 / 其他 / 以上都不是」（不是禁用，是不画）；搜索框是全屏唯一文本输入，回车只收起键盘（iOS return 键 label = 完成/收起，不是「创建」）；归档分组「可找回，不可挑」 |
| 失败落点 | 挂载只传节点 id，节点失效 → 强制刷新树重挑、不静默改挂（U2.4 §7.2） |

### `m2-cause-nomatch` · 成因①无匹配（U2.3，TS-05，空态）

| | |
|---|---|
| 触发 | 四成因错误码对照之 NO_MATCH（§六 6.1） |
| 反馈 | §六①原文 + 自己挑一个主 +「就这样留着」，无「再试一次」；副句「不会替你硬凑一个最像的」；「就这样留着」是正式出口。屏上「不是这条记录记错了」为 `打标与未分类` §六 ① 上屏原文逐字照抄，非评价语义 |
| 失败落点 | 本屏即无匹配的落点；交付评论未登记本屏再往下的失败分支 |

### `m2-cause-quota` · 成因③额度不足（U2.3，TS-06，受限态）

| | |
|---|---|
| 触发 | 四成因错误码对照之 QUOTA_EXHAUSTED（§六 6.1） |
| 反馈 | §六③原文含「记录已经存下来了」，主按钮 = 免费兜底，购买只是文本按钮「看看档位」 |
| 失败落点 | 本屏即受限态的落点；交付评论未登记本屏再往下的失败分支 |

### `m2-queue-offline` · 成因② + 待补队列（U2.3 + U2.5 全部像素，失败态）

| | |
|---|---|
| 触发 | 四成因错误码对照之 SERVER_ERROR（§六 6.1） |
| 反馈 | 离线细条 +「攒了 3 条 · 会自己一条条再认」计数，两格均不可点；无第几次、无倒计时 |
| 失败落点 | 本屏即失败态的落点；交付评论未登记本屏再往下的失败分支 |

### `m2-ipad` · S-TAG 核心屏 iPad 横屏（主态）

| | |
|---|---|
| 触发 | ≥1024 横屏双列 |
| 反馈 | 左栏是内容不是菜单 —— 未分类流本身，随「还没对上的 · 7 条 / 看全部记录」筛选整栏换掉；每行自带成因徽标，一眼看出这一条属于哪种，四种成因没有摊成并列区块。右栏 = 当前记录处理区，与 iPhone 信息顺序完全一致，只改排布。候选集选择两档同用整屏 sheet（m2-tree） |
| 失败落点 | 与 iPhone 档同源（信息顺序完全一致，只改排布）；交付评论未单独登记 iPad 档的失败分支 |

另登记：U2.1 四段管线无独立屏（真源明写「管线全程不与用户交互」）；U2.2 十态徽标文字已逐字落在各稿状态位与 iPad 左栏（看一下? / 没对上 / 稍后再认 / 已对上 / 丢掉了 / 考点已归档），TS-03 与 TS-07 同形不区分来源。

## 它服务于哪个关卡
