## 一、这一屏只回答三件事

**有没有 · 几次 · 多久前。** 一格都不能多。

| ✅ 屏幕上允许出现 | ❌ 永远不出现 |
|---|---|
| 「近 5 年考过 7 次」 | 「重点考点」「必考」 |
| 「你没碰过」 | 「你不会」「掌握度 30%」 |
| 「你碰过 3 次,最近 6 天前」 | 「建议复习」「该复习了」 |
| 「来源:某网课 · 某讲义」 | 任何题目内容、任何讲解 |

🔴 **不做学科判断**。屏幕上的每一个字要么来自骨架的统计字段,要么来自用户自己的行为记录。
**要不要学、先学哪个,是用户自己的事** —— 产品给的是差集,不是建议。

## 二、`S-BLIND` 盲区总览

### 2.1 元素清单

| 区 | 元素 | 取值来源 | 为空时 |
|---|---|---|---|
| 顶 | 科目切换 | 用户已有记录涉及的科目 + 全部科目 | 只有一个科目时**不显示切换器** |
| 一 | **一句话摘要**:「{subject} 一共 {total} 个考点,你碰过 {touched} 个,没碰过 {empty} 个」 | `GET /coverage/summary` | 见 §2.4 空态 |
| 二 | **「先看这些」列表**(Top N) | `GET /coverage/blindspots?top=20&orderBy=recent5y_count` | 见 §2.4 |
| 二 | 每行:考点名 · 「近 5 年 {n} 次」· 「你没碰过」 | 骨架统计字段 + 我的触达 | —— |
| 三 | 「按章看全部」入口 | 骨架树 `GET /syllabus/tree` | —— |
| 四 | 「我已经会了」的数量 + 入口 | 断言集合 | 为 0 时隐藏 |

**排序口径写在屏幕上**:列表顶部一行小字「按近 5 年出现次数排」,并且**可切换**为「按最久没碰」。
⚠️ **排序口径必须可见。** 一个不说明排序依据的「推荐列表」会被读成产品在做学科判断。

### 2.2 每一行长什么样

```
行政处罚的种类                     近 5 年 7 次
你没碰过                                    →
```

- 左上:考点名(截断两行)
- 右上:出现次数,**这是骨架的统计字段,不是评价**
- 左下:我的状态,三种之一:`你没碰过` / `你碰过 {n} 次,最近 {d} 天前` / `你标了「已经会了」`
- 点整行 → `S-NODE`

### 2.3 断言:「我已经会了」与「我卡住了」

| 断言 | 用户从哪点 | 效果 | 端点 |
|---|---|---|---|
| **我已经会了** | `S-NODE` 内 | 该考点**从盲区榜排除**,但**仍计入「没碰过」的概览计数**(单列不并入) | `POST /assertions` |
| 取消断言 | 同上 | 回到榜里 | `DELETE /assertions` |
| **我卡住了**(反向断言) | 🚧 **界面还没有** | —— | 见 §六 缺口 `B-1` |

⚠️ **概览与榜单口径不一致是已知的**(`技术架构与接口契约` §6.4 `R-100`):
声明 3 个已会之后,概览仍说「没碰过 10 个」,而榜里只列得出 7 个。
**屏幕上必须解释这一句**:概览数字下方小字「其中 {n} 个你标了『已经会了』,没在下面列出来」。**不解释就是产品在自相矛盾**。

### 2.4 空态(三种,文案完全不同)

| 情况 | 文案 | 给什么入口 |
|---|---|---|
| **骨架没建好** | 「这个科目的考点表还没建好」 | 只给「去记一条」——**不给任何等待提示、不给进度条** |
| **骨架有,但一条记录都没有** | 「你还没记过东西,所以现在整张表都是没碰过」 | 「记一条」(主) · 「先看看有哪些考点」(次,进骨架树) |
| **全部碰过** | 「这个科目的考点你都碰过至少一次」 | 「按最久没碰排一遍」 |

### 2.5 加载与失败

- 首屏骨架占位:摘要一行 + 5 行列表形状,**不转圈**
- 覆盖层正在重算(刚合并账号 / 刚删记录):显示上一次的数字 + 一行小字「正在重新算」,**不显示错误、不清空**
- 请求失败:错误态 + 重试;**已经缓存的上一次结果继续显示**并标「这是刚才的数据」

## 三、`S-NODE` 考点详情

### 3.1 元素清单

| 元素 | 取值 | 为空时 |
|---|---|---|
| 考点名 + 所在章节路径 | 骨架树 | —— |
| **近 5 年出现次数** | 骨架统计字段 | 「这个考点没有出现次数记录」 |
| **最近一次出现在哪一年** | 骨架统计字段 | 隐藏 |
| **你碰过几次** | 我的触达计数 | 「你没碰过」 |
| **最近一次多久前** | 我的最近触达 | 隐藏 |
| **来源集合** | 我的记录里的来源名称 | 隐藏 |
| 我的相关记录列表 | 挂在这个考点上的记录(时间 + 摘要) | 「没有相关记录」 |
| 「我已经会了」开关 | 断言状态 | —— |
| 「去记一条」 | —— | 常驻 |
| 「把这个考点带去问 AI」 | —— | 进 [导出与问AI](导出与问AI.md) |

🔴 **这一屏没有讲解字段**(`R-05`,`GET /syllabus/nodes/{id}` 明写「没有讲解字段」)。
**不许加**:题目、解析、例题、推荐资料、相关课程。加任何一个都是越过「不做学科教研」这条边界。

### 3.2 交互

| 动作 | 行为 |
|---|---|
| 点「我已经会了」 | 立刻置灰该考点、Toast「标了『已经会了』」;**乐观更新**,失败则回滚并提示 |
| 再点一次 | 取消;不需要二次确认 |
| 点一条相关记录 | 进 `S-TL` 该条详情 |
| 点来源名 | **不可点** —— 来源只是名称,产品不为它建页面(不存储机构课程内容) |
| 返回 | 回 `S-BLIND` 并**保持滚动位置** |

## 四、按章看全部(骨架树)

| 规则 | 说明 |
|---|---|
| 数据 | `GET /syllabus/tree?subject=&withCoverage=true`,**单模块整棵树一次返回,前端不做懒加载** |
| 展开 | 默认展开到第 2 层;第 3 层是叶子(考点) |
| 每个节点右侧 | 「{碰过}/{总数}」 —— **只有计数,没有百分比、没有进度条** |
| 叶子节点 | 点击进 `S-NODE` |
| 搜索 | 树内搜考点名,**只搜名称,不搜内容** |

⚠️ **不做进度条**:进度条会把「覆盖度」读成「学习进度」,而覆盖度只是「碰过没碰过」,它不衡量掌握。

## 五、异常全集

| # | 触发 | 表现 | 文案 | 下一步 |
|---|---|---|---|---|
| `B-01` | 骨架为空 | 空态 | 见 §2.4 | 去记一条 |
| `B-02` | 概览与榜单数字对不上 | **就地解释** | 「其中 {n} 个你标了『已经会了』」 | —— |
| `B-03` | 覆盖层重算中 | 旧数 + 小字 | 「正在重新算」 | 等 |
| `B-04` | 断言写入失败 | 回滚 + Toast | 「没标上,再试一次」 | 重试 |
| `B-05` | 树太大导致首屏慢 | 骨架占位 | —— | 见 §六 `B-3` |
| `B-06` | 科目下一条记录都没有 | 空态 | 见 §2.4 | 记一条 |
| `B-07` | 网络失败但有缓存 | 显示缓存 + 标记 | 「这是刚才的数据」 | 重试 |
| `B-08` | 网络失败且无缓存 | 错误态 | 「没拉到考点表」 | 重试 |
| `B-09` | 用户把全部考点都断言成「已经会了」 | 空态 | 「都标成会了。要看全部,去掉几个标记就行」 | 去树 |

## 六、缺口登记

| # | 缺口 | 卡在哪 |
|---|---|---|
| `B-1` | **「我卡住了」反向断言没有界面** | `模块 D · 差集层` 已登记它未定义;`技术架构与接口契约` §6.4 只有正向断言。**在它定下来之前,`S-NODE` 上不放这个按钮** |
| `B-2` | **多科目的切换与合并** | 用户同时准备两门考试时,概览是分科目还是合并?没定 |
| `B-3` | **整棵树一次返回的上限** | 契约说不做懒加载;**多大的树会让首屏不可接受,没有实测数**。这是技术侧要给的数 |
| `B-4` | **「近 5 年」这个窗口谁定的** | 屏幕上写死了「近 5 年」,但这个窗口来自骨架数据本身。窗口变了,文案要跟着变 —— **它属于[骨架数据采集流水线](../../data/骨架数据采集流水线.md)** |
