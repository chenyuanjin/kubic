# H5 交互说明（Web 主形态）

基线：`origin/v1` @ `000d403`，fetch 于 2026-09-05。
底座：`kubi-80-v10-blueprint` 的 `tokens.css` + `v10.css`，**逐字节复制，`cmp` 已验同**，不带自己的 token。
本目录只加一个差分层 `h5.css`（80 行），差分五处，每处都指得回 `M6` 的一行。

## 这份稿的范围

`U6.1 §6.1` 把 Web / H5 定为**主形态**：十四屏全在这里，其余三个端是它的再分发。
`KUBI-81~88` 那八份稿画的是 iPhone / iPad 两档 —— **主形态一屏都没有**，
所以这份补的是那个差分基准，不是第九份模块稿。

**不重画的东西**：空态、加载态、通用错误态、各模块的业务流程 —— 换端不改变它们，
重画只会产生第二份说法。这里只画**换了端就不成立**的部分。

## 一、逐屏：触发 → 反馈 → 失败落点

### `S-HOME` 首页 · `home.html`

| | |
|---|---|
| 触发 | 打开地址（任意 route id 都先过门，见下） |
| 反馈 | `GET /api/v1/records?limit=3` 回来前列表位是 `.ph` 压平灰块，不转圈；回来后台账行就位 |
| 失败落点 | `SERVER_ERROR` / `NETWORK_TIMEOUT` → 列表位换成可重试档 `C-ERR`；**「今天记了 n 条」与蓝面那块不进错误态**，它们的数来自本地已落库的记录，网络挂了这两个数照样成立 |
| H5 差分 | ① 无状态条 ② 无屏内返回（`P-NAV` = 浏览器返回键）③ `.dock` 走 `position:sticky` + `env(safe-area-inset-bottom)` ④ 「拍」那一格在非安全上下文下**不渲染** |

`.dock` 为什么不能 `fixed`：iOS Safari 地址栏收起时 `fixed` 元素会跳一下，
而屏底动作区是全产品动作的固定住址 —— 住址会跳，就不是住址了。
`100dvh` 同理：`100vh` 在 Safari 上把地址栏算进去，主按钮会被压到折叠线以下。

### `S-BLIND` 盲区总览 · `blind.html`（双列档，H5 唯一的结构性差分）

| | |
|---|---|
| 触发 | 首页「看盲区」，或直接开这个 route id |
| 反馈 | `GET /api/v1/coverage/summary?subject=<code>` 与 `GET /api/v1/coverage/blindspots?subject=<code>&orderBy=recent5y_count&filter=untouched` 两个请求；摘要三个数**同时**上屏，不一个一个蹦 |
| 失败落点 | `SUBJECT_NOT_LOADED` → 停在本屏，下一步是换科目；`SYLLABUS_EMPTY` → 空态（本该有，现在没有）；`SYLLABUS_DATA_BROKEN` → 不可重试档，不给重试按钮 |
| 重算态 | 一个旧数字都不出现：`.ph` 占位，不加删除线、不调透明度、不配「可能不准」小字 |
| H5 差分 | 视口 ≥1024 进双列（`U6.3`）：左栏 300（下限 260）· 右栏最小 480 · 内容区 1120 · 页边距 40 |

🔴 **左栏是内容不是菜单，判据三条**（并排放的时候数这三条，不看颜色）：
① 它装的是骨架树，换一个科目整栏换掉；② 它一条也不列举别的屏；③ 它没有选中态高亮条，只有一条发丝线分栏。

⚪ **720–1024 落哪一档本稿不拍**（`U6.3 §五-1` 没人验过，`KUBI-80` 也标了 ⚪）。
`h5.css` 里 `max-width:1023px` 走单列，那是**实现兜底不是产品结论**。

### `S-REC` 记一次（图片）· `rec.html`

| | |
|---|---|
| 触发 | 屏底「拍」→ `<input type="file" accept="image/*" capture="environment">` 调起系统相机 |
| 反馈 | 图片进页面即出现留存三处；「记下」提交 `POST /api/v1/records/batch` |
| 失败落点 | `UNSUPPORTED_IMAGE_FORMAT` / `IMAGE_TOO_MANY` → 行内 `C-INLINE`，图不丢；`QUOTA_EXHAUSTED` → 受限态，`C-LIMIT` 的主按钮永远是免费兜底；`MISSING_CLIENT_TOKEN` / `VALIDATION_FAILED` 是端自己的 bug，不做用户文案 |

🔴 **网页上这条红线的落法和 App 不一样，必须写下来**：
App 有应用内相机，可以在快门与落盘之间插一屏；网页没有 —— `input[capture]` 一按，
系统相机拍完图**立刻**进页面。所以**同意那一行必须排在「拍一张」上面，且未勾选时按钮不可按**。
顺序反了，「挡在收图之前」这条红线在网页上就等于没有。

### `S-RAW` 原图管理 · `raw.html`（全矩阵唯一的「降级」格）

`U6.2 §2.2` 里 `S-RAW × Web` 标的是**降级**，降的是**存储**：
按 origin 隔离、可被浏览器驱逐、用户清站点数据会一起清、隐私模式下不可用。

| | |
|---|---|
| 触发 | 设置 → 原图管理 |
| 反馈 | 常驻说明（关不掉）+ 一条可关闭提示 + 缩略图栅格（窄屏 2 列 / ≥1024 四列）+ 留存三处 |
| 失败落点 | 原图被浏览器清掉 → `states.html` 第 1 张：**不给重试按钮**，说清谁删的、还剩什么 |

🔴 **降的是存储，不是承诺**（`U6.1 §6.5`：桌面壳 / 移动 App / Web 三处齐全不因端而弱化）。
留存三处在这一屏与底座 `rec.html` **逐字相同、同号字、同一条左边线**，
Web 独有的是**多**一块告知，不是**少**一处承诺。

🔴 **常驻说明与可关闭提示不合并**：常驻说明是告知，关不掉；提示是提示，可以关。
合并等于把告知做成了可以关掉的东西。且常驻说明**必须点名「浏览器可能清理」** ——
只写「建议装桌面版」是推广不是告知（`U6.2 §2.3` 那一行的原判据）。

### 门（未登录访问任何 route id）· `states.html` 第 4 张

| | |
|---|---|
| 触发 | 任何 route id，未登录 |
| 反馈 | **地址不变**，原地渲染门（`U6.1 §2.7`：门只有里外，没有历史） |
| 失败落点 | `UNAUTHORIZED` / `SESSION_EXPIRED` / `TOKEN_EXPIRED` 三个码在门上是**同一张屏**，端不为它们写三句话 |

🔴 **不 redirect 到 `/login` 再跳回来**：那会在浏览器历史里留两条，
用户按一下浏览器返回键就弹回门里 —— 而 `P-NAV` 在这个端上就是那个键。

🔴 **URL 红线**（`U6.1 §2.7`）：地址里只允许不透明 id 与固定枚举值。
不放用户输入的原文、来源课程名、机构名 —— URL 会进浏览器历史、访问日志、
分享出去的那条链接、以及截图。这是「不存题干」在多端上的落点。

### `S-BILL` 额度 · `states.html` 第 3 张

`U6.2 §2.2` 这一格是 ⚠️ **支付通道 🚧 待定**，不是「完整」。
所以本稿**不画购买流程**：额度照常显示，购买按钮画成不可按并把原因写在它上面。
⚪ 这是登记，不是设计一条不存在的路 —— 也不拿「敬请期待」把空白填上。

## 二、H5 独有的四态（`states.html`）

| # | 态 | 为什么它只在这个端上存在 |
|---|---|---|
| 1 | 原图被浏览器清掉 | 别的端没有「宿主会替你删数据」这件事 |
| 2 | 非安全上下文 → 拍的入口**不渲染** | 别的端不存在 `http://` 打开产品这个可能 |
| 3 | `S-BILL` 支付通道待定 | iOS 走 Apple 内购，这一格在 App 上是完整的 |
| 4 | 门 · 地址不变 | 别的端没有地址栏 |

第 2 张为什么是**不渲染**而不是灰掉：灰掉 = 「显示入口但点了提示去别处」，
`U6.1 §2.6` 明确不承认这第四格。**「没有权限」与「这个地址做不到」是两句话**，
后者连话都不说 —— 说了反而像是用户做错了什么。

## 三、无障碍：H5 上多出来的三条

`U6.4` 的下限六条全部落在底座 token 上，不重复。H5 端多出来的只有这三条：

1. **键盘可达**：`U6.4 §154` 要求 Web 上十四屏全部功能只用键盘完成。
   底座 `v10.css` 的 `:focus-visible{outline:2px solid var(--ink);outline-offset:3px}` 已覆盖；
   本层不改它，也不加 `outline:none`。
2. **左滑删除在 Web 上是行内按钮**（`U6.4 §161`）—— 触控手势在这个端上不是唯一手法。
3. **200% 缩放**：`h5.css` 全部尺寸走 token 与 `dvh`，没有一处 `px` 写死的容器高度，
   放大到 200% 走单列重排，不横向滚动。

## 四、本稿没有自己拍的（⚪ 照原样登记）

1. ⚪ **720–1024 落哪一档** —— 与 `KUBI-80` 同一条，不拍。
2. ⚪ **`S-BILL × Web` 支付通道** —— 没有降到哪里就没有界面形态，只画不可按的按钮 + 原因。
3. ⚪ **原图在 Web 上存哪** —— IndexedDB / OPFS 的选型是技术侧的事；
   界面只承诺「在这台设备上、浏览器可能清理」，这两句在两种实现下都成立。
4. ⚪ **`S-ASK × Web` 发图入口** —— `U6.2` 写「非安全上下文下不出现」，
   安全上下文下它随本端原图通道走，而原图通道在 Web 上是降级格 —— 这两条的交集本稿不裁定。
